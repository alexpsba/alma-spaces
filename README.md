# ALMA — Spaces with purpose

Digital concept for ALMA: interior design + construction + project management.

## Product idea

The site is not just a portfolio. It introduces **ALMA Space Planner**, a guided project-intake experience that helps a potential client turn an idea into a structured brief before speaking with Jessica.

Current V1 is a front-end prototype. It captures project intent, room/type, stage, style, priorities and contact information locally in the browser and produces a concise project brief.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Cloudflare Workers static assets via Wrangler.

```bash
npm run deploy
```
